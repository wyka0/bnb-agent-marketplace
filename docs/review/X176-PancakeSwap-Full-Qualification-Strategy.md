## 4 · Critical Distinction

| Do NOT equate                                       | Audit discipline                                                                                                                                                                                                                                                               |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| PancakeSwap API/RPC data **with** trader/LP benefit | **Data ≠ benefit.** `eth_call` + price API rows are **data**; benefit requires a **trader/LP outcome** (better LP placement, yield found, slippage reduced, demand spotted) that is **measured**. Option B has **data** (TVL/price) but no measured outcome beyond “research”. |
| Read-only analytics **with** automated trading      | **Analytics ≠ automation.** `intelligence.ts` is **read-only** (`eth_call` + `GET` price only, `PANCAKESWAP_READ_ONLY_BOUNDARY` verified via comment-stripped scan). No `swap`/`addLiquidity` exists. Do not claim “safe automated swaps” — safety is via _not_ automating.    |
| Recommendation **with** proven outcome              | **Recommendation ≠ proof.** Pool cards ranked by TVL are **recommendations** (here’s a pool with real TVL). No `before/after` (e.g., “LP moved to this pool and APR +X%”) is measured.                                                                                         |
| Sample (W=16) **with** market census                | **Sample ≠ market.** Head/tail window is **honestly labeled** as sample scope; it is not a top-pools claim.                                                                                                                                                                    |

Do not invent a measurable benefit.
