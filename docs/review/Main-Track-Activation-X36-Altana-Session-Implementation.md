### Blocking follow-up

The genuine chain-97 session lifecycle and post-revoke proof are complete, but
the marketplace is not yet eligible as a product because it lacks authenticated
wallet/session persistence and an active-session revoke flow. The minimum next
implementation is encrypted server-side session-signer persistence (or an
approved user-controlled passkey custody path), authenticated ownership, live
session reads, and a revoke endpoint that calls `client.revokeSession` for the
persisted active session. No additional chain transaction was submitted after
the successful X.36 proof.
